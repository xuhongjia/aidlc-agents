# Final verification supplement

Required analysis input must be an actual qa test-run, never Intake Test Design, DEV self-tests, or Jira Done. Check fixed cases/source AC, candidate, test-environment runtime identity, data version, and every required UI/manual item. Missing coverage/execution, stale/truncated evidence, missing human records, or identity mismatch blocks any passing conclusion.

After QA evidence is complete, the parent dispatches actually independent Architecture/Quality Reviewers under core gate-execution, then a fresh collector. Only this node executes formal dual Gates. Quality Reviewer checks TDD/affected regressions and QA business-acceptance evidence. Reused valid execution records retain their original executors; never re-sign them. Reviewers/collector do not modify this round's code/tests/cases.

Candidate/rule/case-version changes invalidate affected evidence and return to the parent for controlled revision. Reach Implementation Verified Handoff only with dual Gates, full AC coverage, valid approvals, and no drift. Sync status is separate: the parent writes result summaries/evidence links under authorization, without automatic Jira Done, business acceptance, or production release.
