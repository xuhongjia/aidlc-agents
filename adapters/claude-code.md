## AIDLC Agents

For software delivery action requests (new features, behavior changes, bug fixes), even without an AIDLC keyword, or explicit AIDLC controls, first read only `.aidlc/system/skills/orchestration/aidlc/SKILL.md`. Let the router infer standard/enhance/fix and choose control/delivery instructions before loading protocols. Respect explicit user constraints; status, review, explanation or discussion alone does not start delivery. Existing work retains its frozen workflow. A valid fresh dispatched child uses frozen instruction_refs instead of parent routing.

Before parent delivery, follow `.aidlc/system/workflow/preflight.md`: check GitHub, update new work first, keep existing work pinned, reload router/contracts after updates. Status/approval/closure controls skip this check; children never update/install methods.

The parent only coordinates dependencies, dispatch, results and approvals. EVERY stage/rework needs a NEW fresh-context child given dispatch and required approved references, never parent history, inline execution or a reused worker. Require actual spawn/isolation/collection probe evidence; unavailable/unknown blocks. A dispatched child executes only its assignment, without recursively delegating the whole stage. Follow `.aidlc/system/workflow/protocol.md` and orchestration.md on the delivery route for parallelism/result checks.

Approval is manual unless an exact work-scoped checkpoint_low_risk/auto_low_risk delegation is valid under `.aidlc/system/workflow/approval.md`; delegated decisions are not human sign-offs. Checkpoint keeps entry/final Verify human-approved. Implement correction needs a separate explicit budget. Children cannot approve/advance.

Preserve project instructions, user edits and host permissions. Missing/conflicting files or evidence block; never fabricate execution, approval or PASS. This bridge grants no extra permissions and installs no runtime, hooks or global settings.

Use native non-fork delegation, preserving CLAUDE.md rules/imports. Loading a Skill is not delegation.
