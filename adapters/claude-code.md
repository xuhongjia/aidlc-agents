## AIDLC Agents

For AIDLC requirements, implementation, review, or continuation requests, explicitly read these files from the repository root:

1. `.aidlc/system/skills/aidlc/SKILL.md`
2. `.aidlc/system/workflow/protocol.md`

Use the router to load only the current stage and its required context. Read the current work record before continuing. Stop at required human approvals; record only the user's actual decision for the exact artifact revision presented. Never substitute an agent review for human approval.

Keep existing CLAUDE.md instructions, rules, and permissions in effect. This bridge does not install native subagents, hooks, or permissions. If the canonical files are unavailable or instructions conflict, report the issue before proceeding with the AIDLC workflow. Do not claim a command, test, or gate ran without execution evidence.
