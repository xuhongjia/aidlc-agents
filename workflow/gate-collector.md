Direct dispatch reserves collector_run_id; it proves no executed collector. Parent dispatches both Reviewers first, then the real independent collector. If preparation is uncertain, the initial collector returns Reviewer requests, releases its slot/ends; parent collects leaves and dispatches a fresh collector. Never execute their checks or claim reruns.

Cite original Gate files; verify actual identities/digests/lineage, checks/raw evidence and every FR/NFR→AC/approved exclusion→Oracle/actual evidence. Check Quality Reviewer's TDD/exceptions/final-candidate regressions/fix before-after/adjacent checks; manual AC requires real observations. Gates never replace acceptance coverage.

Reuse only valid continuation_refs for the same step/revision/candidate/graph/rules/inputs. execution_refs retain origin_dispatch_ref/origin_result_ref/gate_ref, original run_id/agent_id, workflow_ref/step_id/revision/candidate_ref/baseline_refs/input_refs. Match original hashes; never change identities or cache over latest pipeline checks.

Reverify new candidates/rerun affected Gates at least. Reuse requires complete unchanged-dependency proof; never retarget hashes.
