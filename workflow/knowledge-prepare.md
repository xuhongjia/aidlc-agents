# Prepare knowledge before approval

Full verification/learning children with knowledge.prepare create evidence/knowledge/ID-vN.json from locked snapshot template in result.evidence. Collector prepares, never duplicate leaves. Parent supplies relevant index/prior version/full targets/approval sources. No content means no item. Unconfigured targets still allow real local knowledge, destinations=[], no corporate access.

| type | Verify | Learn |
|---|---|---|
| architecture | Approved design/ADR/constraints; conformance/gaps separate | Observed operational tradeoffs/limits/improvements/design differences |
| quality | Approved design/AC-test mapping/Oracle; Gates/gaps separate | Escaped defects/missed tests/effective-ineffective checks/improvements |
| anti_pattern | Practices evidenced by findings/negative validation | Antipatterns confirmed by feedback |
| lesson | Evidenced reproduction/troubleshooting/environment cautions/practices | Feedback/corrections/applicability changes |

Complete approved design: content.design_body preserves body; source.design_refs cites actual approved reviews/digests. Summaries are not full text; approved design is not verified implementation. Redact sensitive sections before freezing, record redactions/label “redacted projection”; never publish unsafe content. Change/verification-only architecture/quality uses origin=derived/“derived item”, no full-design-report requirement. Missing design text means design_body=null.

Learn uses origin=observed_revision/original design sources/prior version; append revisions, never replace approvals. Items retain stable ID/increasing version/type/source work/stage/step/workflow_ref/review/evidence/applicability/invalid_when. Separate approved_design/verified_in_candidate/observed/proposed claims. Antipatterns need condition/bad_practice/consequence/alternative/evidence/limitations. No finding means no item.

Validate original FR/NFR→AC/approved exclusion→tests/Oracle→actual evidence; gaps block. Knowledge replaces neither Gates nor acceptance. Auto approval creates no facts/corporate-rule/Oracle/threshold/Skill changes.

Freeze title/body/sources/redactions/full destinations before approval, not mutable IDs alone. Return paths/actual digests/new decisions. Content changes need new review; children never publish/promote index/edit historical approvals. Extra targets need explicit new authority binding original snapshots/exact targets without snapshot edits. Parent promotes/dispatches separate sync Hook only after approval validation.
