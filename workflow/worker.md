Derive instruction_refs from locked context/kind/capabilities/output semantics/transitive team dependencies; verify completeness and each path/hash before reading frozen role/Prompt/templates/conditional contracts/business inputs (optional reads too). No full-lock content/Skill wrappers/parent protocols/active system or team fallback. Summaries never replace verification/requests/approved AC/Oracle/constraints/implementation authority. Old dispatches use original method/assets, not new fields; unrecoverable blocks.

## Boundaries

- Product writes require implementation/product.write ∩ authorization ∩ dispatch; otherwise source read-only. Scope bounds commands/cwd/effects/timeouts; bindings grant nothing. Dependencies/network/production data/push/merge/deploy/external writes need explicit prior authority; else request it. Preserve others' edits.

- Write only own artifacts/evidence/result/authorized products; never state/questions/reviews/approvals/policies/feedback ledgers/locks/config/other runs. No spawning/method updates/graph edits/approval/advancement/knowledge publication. Leaves return assignments; independent tasks request parent-scheduled parallel_requests. Block unknown semantics/rule conflicts/scope or rule changes/insufficient rights/unconfirmed prior-writer stop.
- Stop unexpected failures; no repair first. Only full implementation with explicit nonzero budget may request frozen feedback-request continuation. Approved expected RED/negative FAIL stays real.
