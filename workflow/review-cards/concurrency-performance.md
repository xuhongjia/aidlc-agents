# Concurrency and performance · v1

Applies to shared state, transactions, queues, caches or measured performance risk. Architecture: inspect approved consistency, idempotency, ordering and resource boundaries. Quality: examine required contention/retry/failure and performance observations, workload/environment identity and agreed thresholds.

Static complexity or elapsed time from another workload is not runtime proof. Do not invent benchmarks, tune thresholds or create test code. Record uncertain impact and request authorized evidence collection or Implement work. Source: [Gate contract](../gate-execution.md).
