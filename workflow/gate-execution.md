# Independent dual Gates

Dispatch architecture-gate-reviewer, quality-gate-reviewer, then fresh Verify collector: distinct actual Agents/runs independent of all Implement contributors. DEV self-tests cannot substitute. Each Gate needs ≥1 relevant nonempty blocking check/all mandatory approved rules. Missing design/code returns blocked to producers; Verify adds/weakens no rules.

Verify approved baseline/entry digests/authority/same complete frozen candidate; enumerate/hash before/after under worker. Parallelism requires separate reports/temp directories/no shared writable DB/cache/port/environment; otherwise serialize. Requesting collectors release slots/end. No Agent per command.

dispatch.gate_assignment={kind,collector_run_id} fixes ownership; locked context.gate_reviewers fixes role/gate-review Prompt. required_evidence includes assigned Gate only. Reviewers write only own architecture-gate.json/quality-gate.json/raw logs. Collector cites originals/verifies identity/digest/lineage, never claims reruns.

Frozen gate-result records candidate/baseline_refs/times/environment/checks/status. Checks retain ID, blocking/advisory, actual command/cwd/exit code/result, executed_count/skipped_count, success criteria/rule assertions/raw_evidence paths/actual digests. PASS needs nonzero relevant blocking assertions/all required checks passing. Zero/all-skipped/empty/irrelevant scope, tool failure/timeouts, missing/truncated/unknown evidence/drift blocks. Full reports stay in files; summaries prove no PASS. Project tools/permissions enforce CI.

Quality Reviewer checks every Task's TDD/exceptions/final-candidate regression/per-AC evidence/fix differences/adjacent regressions/real manual observations without TDD execution Skills. Collector checks Gates/FR/NFR completeness/AC/raw evidence; Gates never replace acceptance coverage.

## CI/resumption

Follow approved local/ci/hybrid rules. Verify bindings collect CI; Reviewers independently check job/attempt/configuration/rule/commit/source/candidate/assertions, never normalized PASS. command=approved job; absent exit_code/cwd=null. Verify alone owns CD/waits; Reviewers add no bindings/monitors. Unready results return gaps; unfinished mandatory CI/CD blocks review.

Reuse only same step/revision/candidate/graph/rules/inputs. execution_refs retains origin_dispatch_ref/origin_result_ref/gate_ref, original run_id/agent_id, workflow_ref/step_id/revision/candidate_ref/baseline_refs/input_refs. Original hashes must match; never change identities/cache over latest pipeline checks.

## Handoff

Implement submits unverified candidates. Parent handoff needs both Gates, all AC, TDD, complete evidence, no drift and required approvals. FAIL requires new Implement/controlled-repair authority. Reverify new candidates/rerun affected Gates at least. Reuse needs complete unchanged-dependency proof; never retarget hashes/self-repair/self-approve.
