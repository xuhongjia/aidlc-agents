# Report retained work evidence

The existing parent reads [measurement](../../../workflow/measurement.md) and [report usage](../../../docs/measurement.md). Load only selected work records, frozen policy and referenced evidence; do not dispatch a reporting Agent or add this Skill to ordinary stage context.

1. Fix the requested work population, root business units, compatible cohorts and observation cutoff. Retain failed/cancelled work and source coverage. Old-work reconstruction is retrospective and uses existing sources only; missing inputs remain missing.
2. Verify ledger/record revisions, source references, hashes, correction chains, original timestamps and candidate/approval links. A self-authored confirmation is not authoritative evidence. Preserve sanitized originals, retention limits and all excluded/missing inputs.
3. Use the frozen read-only helper through the existing JSON entry. Save its complete result and exit status through the parent, then derive the bounded display from that saved result. A blocked result permits a limitations report, never unsupported measurement claims. Without the required runtime, report the unavailable calculation; install nothing and invent no equivalent result.
4. Present observed outcomes, complete comparable human effort differences, cycle/wait time, quality/rework, actual usage/cost and availability only to the extent supported. Separate actual, self-reported and estimated data. No baseline means no savings percentage; no complete all-role effort means no net-effort claim. Task/SP/token growth does not prove AI productivity, causal effect, capacity or cash savings.
5. Retain report input digests, policy revision, formulas, population/denominators, exclusions and limitations. Save the local report only in the business work directory. Publication requires a separately explicit request and existing scoped authority.

Helpers and this Skill grant no Gate PASS, approval, production claim, new data access or external write. Missing mandatory delivery evidence still follows the existing Gate rules.
